Set up the Kobo receiver once

This experimental option targets Kobo Aura on firmware 4.x. Install NickelMenu and NickelDBus 0.2.0 via USB first. No change is needed for browser transfers.

  1. Download the receiver package and copy its .adds folder to your Kobo.
  2. Create a pairing below. Download its configuration and copy config.json into .adds/pageport/ on the Kobo.
  3. Safely eject, turn on Wi-Fi, then choose NickelMenu → Start Pageport receiver. Afterwards, each transfer only needs Accept. Restart the receiver after reboot or USB use.

Keep the Kobo awake while receiving. The receiver saves books under Pageport/ and asks Kobo to import them. It cannot wake a sleeping device. Download setup and removal instructions

The configuration grants access to books you send to this Kobo. Keep it private. If the computer’s Wi-Fi address changes, download the configuration again.

Good to know

Which files can I send?

EPUB, KEPUB and PDF are the best place to start. You can also add CBZ, CBR, MOBI, TXT, RTF, HTML and common image formats. What your Kobo’s browser can download and import depends on its model and firmware, and can be narrower than the formats it reads over USB.

Files are sent as they are, without conversion. A .kepub file is named .kepub.epub for the Kobo browser. The limit is 512 MiB per file.

Does it push books to my Kobo automatically?

You start each download in your Kobo’s browser. No account, cable, or extra software on the Kobo is needed. Pageport can report that a file was served, but cannot confirm that the Kobo imported it into My Books.

Where are my books stored?

In the pageport-data folder beside the app, unless you selected a different folder when starting it. Your library is kept when you close Pageport. Removing a book here deletes only Pageport’s copy; it doesn’t remove your original or a copy already on your Kobo.

Who can access my library?

The management screen is available only on this computer. Devices on your network need the session code to view and download your books. A new code is created each time you launch Pageport; you can also change it from Connect your Kobo.

Use a trusted private network. Downloads travel over local HTTP so the Kobo’s browser can open them. Pause sharing to stop new downloads, or close the app to stop the server.

What about books with DRM or .acsm files?

Pageport doesn’t remove DRM. An ACSM file is a license, not the book itself; use Adobe Digital Editions for books protected with Adobe DRM.

Can I use it without internet?

Pageport needs only a local network. The app includes all its assets and doesn’t send your books to a cloud service. Your Kobo may still need its usual Wi-Fi connection check to succeed.
